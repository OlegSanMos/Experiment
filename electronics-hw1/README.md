## Исходные данные и результаты

Диод: IS = 3 пА, N = 1,05, RS = 10 мОм, TT = 5 нс, CJO = 7 пФ; Rн = 3 кОм, Lвтор = 1 мкГн;
сеть 230 В, 60 Гц; требуется Uвых.ср = 12 В, Kпульс ≤ 0,78 %.

| | Однополупериодный | Мостовой |
|---|---|---|
| Kтр (пункт б) | 20 (12,571 В при 10 мкФ) | 22 (12,252 В при 10 мкФ) |
| Cф1 (пункт в) | 680 мкФ, Kпульс = 0,781 % | 320 мкФ, Kпульс = 0,771 % |
| Стабилизатор (пункт д) | R1 = 360 Ом + BZX84C12VL | R1 = 130 Ом + BZX84C12VL |
| Uвых.ср / Kпульс со стабилизатором | 12,0016 В / 0,0085 % | 12,0021 В / 0,0227 % |
| Сеть +10 % (пункт е) | +5,7 мВ (без стабилизатора +1,60 В) | +10,5 мВ (без стабилизатора +1,45 В) |

Моделирование — ngspice 42 (методичка допускает «любую другую аналогичную программу»);
модели стабилитронов взяты из библиотеки LTspice `standard.dio` (KiCad-Spice-Library), к их именам
добавлена фамилия.

## Пересборка

Нужны ngspice 42, Python 3 (numpy, matplotlib, schemdraw), Node.js с пакетом `docx`,
LibreOffice (Writer + Math) и poppler-utils.

```bash
cd sim && python3 experiments.py && python3 extra.py     # прогоны ngspice (raw-файлы в sim/runs)
cd ../fig && python3 plots.py && python3 schematics.py   # графики и схемы
cd ../report && ./make.sh                                # report.docx + report.pdf
```
