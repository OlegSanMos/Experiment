# Электроника, модуль 4 — ответы на экзаменационные билеты

**[elektronika-modul4-bilety.pdf](elektronika-modul4-bilety.pdf)** — развёрнутые ответы на все 19 вопросов
к экзамену по курсу «Электроника» (поток БИТ, модуль 4, «Логические (цифровые) электронные схемы»),
составленные по лекциям Л. М. Самбурского (МИЭМ НИУ ВШЭ).

- Первая страница — оглавление: нажатие на билет открывает страницу с ответом; в каждом ответе есть
  ссылка «к оглавлению» и на следующий билет, закладки PDF повторяют структуру ответов.
- Иллюстрации — рисунки со слайдов лекций с указанием источника вида [Л16, сл. 9].
- Блоки «Комментарий» — выкладки, выведенные из формул лекций; «Замечание к слайду» — места,
  где на слайде, по-видимому, опечатка.
- В конце — сводка основных формул.

## Состав

| Путь | Что это |
|---|---|
| `elektronika-modul4-bilety.pdf` | итоговый документ (67 страниц) |
| `src/content/t01.md … t19.md` | тексты ответов (Markdown + формулы KaTeX), `formulas.md` — сводка формул |
| `src/build.js`, `src/style.css` | сборка HTML → PDF через Chromium (Playwright) |
| `src/prep_images.py` | вырезка иллюстраций из PDF лекций |
| `src/check_pdf.py`, `src/make.sh` | проверка ссылок оглавления и сборка до стабилизации номеров страниц |
| `konspekty/` | конспекты лекций 1–4, сделанные при первом чтении материалов |

## Пересборка

Нужны Node.js, Python 3 (`pypdf`, `pillow`, `numpy`) и `pdftoppm` (poppler-utils).

```bash
cd src
npm install                       # KaTeX, markdown-it, шрифты PT, Playwright
python3 prep_images.py /путь/к/pdf/лекций   # создаёт img/*.jpg
./make.sh                         # exam.pdf + проверка: все ссылки оглавления ведут на свои билеты
```
