# Лекция 3. Диоды как элементы схем

> Содержание: 1) вольт-амперные и передаточные характеристики; 2) модели диодов;
> 3) анализ диода по большому и малому сигналу.

**Компетенции:** знать основные параметры диода как элемента схемы; понимать ВАХ и передаточную
характеристику (→ уметь определять их для заданных схем); знать схемотехнические модели диода,
различия и критерии выбора (→ анализировать простейшие диодные схемы); понимать анализ по большому
и малому сигналу и малосигнальную модель диода (→ владеть процедурой такого анализа).

## 1. Зачем диод: пример адаптера питания
Сеть: $V_\text{ср.кв} = 230$ В, $f = 50$ Гц → трансформатор → $V_1$ (4 В действ., амплитуда
$V_{1,m} = 4\sqrt2$ В) → **?** → 3,5 В постоянного. На выходе выпрямителя должно остаться напряжение
**одной полярности**: диод ведёт себя как **замкнутая цепь для положительного** напряжения и как
**разомкнутая — для отрицательного**.

## 2. Компоненты с одним p–n-переходом

| Компонент | Что делает | Где применяется |
|---|---|---|
| **Диод (выпрямительный)** | пропускает ток в прямом направлении | выпрямление: двухполярный сигнал → однополярный |
| **Стабилитрон** | пропускает ток в обратном направлении, если напряжение достигает пробойного уровня | защита схем от неправильного подключения питания/входа; стабилизация (лекция 4) |
| **Фотодиод** | генерирует фототок при воздействии света; работает при обратном напряжении | солнечные батареи, фоточувствительные матрицы, датчики |
| **Светодиод** | испускает свет при протекании тока | индикаторы |
| **Варикап** | ёмкость, управляемая напряжением (барьерная ёмкость) | перестройка частоты (приёмопередатчики смартфона, Wi-Fi, Bluetooth) |

## 3. Модель идеального диода и ВАХ

- Напряжение на диоде: $V_Д = V_{АК} = V_А - V_К$ (анод «+», катод «−»).
- **Кусочная (ключевая) модель:** прямое смещение ($V_\text{анода} > V_\text{катода}$) — **замкнутый ключ**;
  обратное ($V_\text{анода} < V_\text{катода}$) — **разомкнутый ключ**.
- Аналогия: труба с **односторонним клапаном** — вода течёт только в одну сторону.
- ВАХ идеального диода: при обратном смещении $R = \infty \Rightarrow I = 0$ (закрыт); при прямом
  $R = 0$ (открыт, **ток определяется окружающей схемой**).
- **ВАХ** — зависимость тока компонента от напряжения на нём (или наоборот).
- Схема измерения ВАХ: источник $E$ → резистор $R$ → диод VD; вольтметр параллельно диоду, амперметр
  последовательно. Диапазон $V_Д$ подбирают, чтобы увидеть все нужные режимы и точки, **с учётом
  ограничений по V, I, P**.

### Метод анализа схем с идеальными диодами (по слайдам 9–10)
1. Подключить к исследуемому фрагменту источник (напряжения).
2. Использовать идеальную модель диода.
3. Рассмотреть **2 состояния диода** (открыт/закрыт); для каждого составить вспомогательную
   эквивалентную схему и записать искомую зависимость.
4. Найти **точку стыковки** решений — где $V_Д = 0$ (смена состояния).

**Пример 1 (диод + резистор последовательно, ВАХ двухполюсника):**
$V_A < 0$ — диод закрыт, $I_A = 0$; $V_A > 0$ — открыт, $I_A = V_A/R_1$ (наклон $1/R_1$).
Стыковка при $V_A = 0$. С более реалистичной моделью характеристика слегка сдвинется.

**Передаточная характеристика** схемы — $V_\text{вых}(V_\text{вх})$.

**Пример 2** ($R_1$ последовательно, диод параллельно выходу, анодом к выходу):

| $V_\text{вх}$ | диод | $V_\text{вых}$ |
|---|---|---|
| $< 0$ | не пропускает ток | $V_\text{вых} = V_\text{вх}$ |
| $> 0$ | пропускает ток (закорачивает выход) | $V_\text{вых} = 0$ |

Решения стыкуются при $V_\text{вх} = 0$, т. к. в этой схеме $V_\text{вх} = 0 \Leftrightarrow V_Д = 0$.

## 4. Применения диода (идеальная модель)

### Однополупериодный выпрямитель
- Неудачный вариант — диод без нагрузки: выход — **«плавающий узел»**.
- Рабочий вариант — с **подтягивающим резистором** $R_1$ (несколько кОм) на землю.
- $V_\text{вх} > 0$: диод открыт, $V_\text{вых} = V_\text{вх}$; $V_\text{вх} < 0$: закрыт,
  $V_\text{вых} = I_{R1}R_1 = 0$.
- Для $V_\text{вх} = V_p\sin\omega t$ **среднее значение** выхода:

$$V_\text{вых,ср} = \frac1T\int_0^T V_\text{вых}(t)\,dt = \frac1T\int_0^{T/2} V_p\sin\omega t\,dt = \frac{V_p}{\pi}$$

### Ограничитель напряжения
- Вспомогательная схема 1: диод + источник $V_B = 1$ В последовательно — ВАХ смещается на $V_B$
  (ток идёт при $V_\text{вх} > V_B$).
- Вспомогательная схема 2: $R_1$ + диод на землю — пропускает на выход отрицательные полупериоды
  (= ограничение по уровню 0).
- Итоговая схема: $R_1$ + диод + $V_B$ на землю — **повторяет $V_\text{вх}$, но ограничивает его
  сверху уровнем $V_B$**: при $V_\text{вх} < V_B$ диод закрыт, $V_\text{вых} = V_\text{вх}$; при
  $V_\text{вх} > V_B$ диод открыт, $V_\text{вых} = V_B$ (с моделью пост. падения — $V_B + V_{Д,откр}$).
- Ограничитель поддерживает $V_\text{вых}$ ниже заданного уровня; источник $V_B$ сдвигает порог
  срабатывания диода с 0 на $V_B$ (формулировка слайда: «помогает диоду пропускать… при
  $V_\text{вх} < V_B$» — по смыслу: пока $V_\text{вх} < V_B$, выход повторяет вход).
- **Передаточная и переходная (во времени) характеристики совпадают по характерным точкам только при
  малой частоте** (на высоких частотах сказываются ёмкости).

### Логический элемент 2ИЛИ на диодах (диодная логика)
Входы $V_A, V_B \in \{0; 3\text{ В}\}$ через диоды D1, D2 на общий выход, подтягивающий резистор
$R_н$ на землю. При высоком напряжении на каком-либо входе его диод открывается и «закорачивает»
выход с этим входом → $V_\text{вых}$ = «1», если хотя бы один вход = «1».

| A | B | $V_\text{вых}$ (идеальные диоды) |
|---|---|---|
| 0 | 0 | 0 |
| 0 | 3 В | 3 В |
| 3 В | 0 | 3 В |
| 3 В | 3 В | 3 В |

(С реальными диодами уровень «1» на выходе ≈ 3 − 0,7 В.) Такие схемы встречались в ранней логике.

## 5. Сравнение моделей диода

| Модель | ВАХ | Точность | Для чего |
|---|---|---|---|
| (а) **идеальный диод** | ключ, $V_{Д,откр} = 0$ | низкая | ручной оценочный расчёт, интуитивный анализ |
| (б) **с постоянным падением напряжения** | ключ + источник $V_{Д,откр} \approx 0{,}7\ldots0{,}8$ В | средняя | ручной расчёт |
| (в) **экспоненциальная (физическая)** | $I_Д = I_{Д0}\exp(V_Д/\varphi_T)$ | высокая | точный численный расчёт |

- В открытом диоде $V_Д \approx V_{Д,откр}$, прямой ток течёт от анода (+) к катоду (−).
- **Факторы выбора модели:** требуемая точность, вычислительные ресурсы, квалификация исполнителя и т.д.

**Пример (сравнение передаточных характеристик):** $V_\text{вх}$ → $R_1$ → выход; от выхода на землю
$R_2$ последовательно с D1.
- Диод закрыт (обе модели): $V_\text{вых} = V_\text{вх}$.
- Идеальная модель, диод открыт ($V_\text{вх} > 0$): $V_\text{вых} = \dfrac{R_2}{R_1+R_2}V_\text{вх}$.
- Модель с пост. падением, диод открыт ($V_\text{вх} > V_{Д,откр}$):
  $I_{R12}(R_1+R_2) = V_\text{вх} - V_{Д,откр}$, $V_\text{вых} = I_{R12}R_2 + V_{Д,откр}$ ⇒

$$V_\text{вых} = (V_\text{вх} - V_{Д,откр})\frac{R_2}{R_1+R_2} + V_{Д,откр}$$

Излом характеристики — при $V_\text{вх} = V_{Д,откр}$, наклон после излома $R_2/(R_1+R_2)$, до — 1.

## 6. Пример расчёта: источник $V_X$ → $R_1 = 1$ кОм → диод
Найти $I_X$ при $V_X = 3$ В и 1 В: (а) экспоненциальная модель, $I_{Д0} = 10^{-16}$ А;
(б) модель с постоянным падением, $V_{Д,откр} = 0{,}8$ В.

Чем пользоваться: законы Ома и Кирхгофа; уравнения компонентов; упрощения ($R + r \approx R$);
**разумные предположения — с последующей проверкой**.

**(а) Экспоненциальная модель** — трансцендентная система:
$V_X = I_XR_1 + V_Д$ (ЗНК) и $I_Д = I_{Д0}\exp(V_Д/\varphi_T)$ (ВАХ).
Решается **итерационно**: задаём $V_Д$ → $I_X$ из ЗНК → новое $V_Д = \varphi_T\ln(I_X/I_{Д0})$ → … до
сходимости (критерий, например, изменение $V_Д$ < 1 мВ).
Начальное предположение $V_Д = 0{,}75$ В:
- $V_X = 3$ В: $I_X = 2{,}25$ мА → $V_Д = 0{,}799$ В → $I_X = 2{,}201$ мА…
- $V_X = 1$ В: $I_X = 0{,}25$ мА → $V_Д = 0{,}742$ В → $I_X = 0{,}258$ мА…

**(б) Модель с постоянным падением** (диод открыт): $I_X = (V_X - 0{,}8)/R_1$ →
**2,2 мА** при 3 В и **0,2 мА** при 1 В.

Вывод: идеализированная модель проста (линейные уравнения), но погрешность растёт при малых
$V_X$ (0,2 vs 0,258 мА ≈ 22 %); экспоненциальная требует нескольких итераций.

## 7. Анализ по малому сигналу

- **Анализ по большому сигналу** — когда сигнал меняется насколько угодно сильно.
- **Малосигнальный анализ** — когда сигнал мало меняется в окрестности **рабочей точки**
  (= точка покоя = смещение) $(V_0, I_0)$ → нелинейные функции можно **линеаризовать** → экономия
  времени и вычислительных ресурсов.

Линеаризация ВАХ диода ($e^x \approx 1 + x$ при малых $x$):

$$I_{D2} = I_{Д0}\exp\frac{V_{D1}+\Delta V_D}{\varphi_T} \approx I_{D1}\left(1 + \frac{\Delta V_D}{\varphi_T}\right)
\;\Rightarrow\; \Delta I_D \approx \frac{\Delta V_D}{\varphi_T}I_{D1}$$

Синусоидальный малый сигнал $V_Д(t) = V_0 + V_p\sin\omega t$:

$$I_Д(t) \approx \underbrace{I_{Д0}\exp\frac{V_0}{\varphi_T}}_{I_0} + \underbrace{\frac{I_0}{\varphi_T}V_p}_{I_p}\sin\omega t$$

⚠️ На слайде 21 во втором слагаемом написано $\frac{\varphi_T}{I_0}V_p$ — это опечатка (неверная
размерность); правильно $I_p = \frac{I_0}{\varphi_T}V_p = V_p/r_\text{диф}$.

**Графический способ:** совместить ось $V_Д$ графика $V_Д(t)$ с осью ВАХ, «спроецировать» входной сигнал
на ВАХ → проекция на вертикальную ось даёт ток $I_Д(t)$; по графику легко найти крайние точки.

### Малосигнальная модель диода
Для малого сигнала зависимости линейны: $i_Д = v_Д/r_\text{диф}$, где **дифференциальное сопротивление**

$$r_\text{диф} = \left(\frac{\partial I_Д}{\partial V_Д}\right)^{-1} \approx \frac{\varphi_T}{I_Д}$$

определяется в **конкретной рабочей точке** (в другой точке — другое значение).
Пример: при $I_Д = 1$ мА $r_\text{диф} \approx 26$ Ом; при 10 мА — 2,6 Ом.

### Процедура расчёта схемы с нелинейными элементами и источниками малого сигнала
1. **Расчёт по постоянному сигналу** (общие модели, напр. $V_{Д,откр}$): найти **рабочую точку**
   (постоянные I, V) и **параметры малосигнальных моделей** нелинейных элементов ($r_\text{диф}$).
2. **Расчёт по переменному сигналу** с малосигнальными моделями (диод → $r_\text{диф}$, постоянные
   источники обнуляются): найти переменные I и V (амплитуда, размах или ср.кв. значение).

Пример: $V_1$ → $R_1$ → диод на землю; по малому сигналу $v_\text{вых} = v_1\dfrac{r_\text{диф}}{R_1 + r_\text{диф}}$.

## Ключевые выводы
1. Основные модели: экспоненциальная, «идеальная», с постоянным падением напряжения.
2. ВАХ компонента — зависимость тока от напряжения (или наоборот), строится в широком диапазоне напряжений.
3. Передаточная характеристика схемы — обычно $V_\text{вых}(V_\text{вх})$, строится в широком диапазоне входа.
4. «Работа с большим сигналом»: напряжения/токи меняются сильно → любые модели большого сигнала.
5. Если изменения в окрестности р.т. малы → нелинейные элементы аппроксимируются линейными («малый сигнал»).
6. Малосигнальная модель диода в простейшем случае — сопротивление $r_\text{диф} \approx \varphi_T/I_Д$.
