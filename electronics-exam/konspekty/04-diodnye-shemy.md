# Лекция 4. Диодные схемы

> Содержание: 1) выпрямители; 2) стабилизаторы; 3) умножители напряжения.
> В лекции используется **модель диода с постоянным падением напряжения** $V_{Д,откр}$.

## 0. Состав адаптера электропитания

```
~u_вх → [Трансформатор] → [Выпрямитель] → [Фильтр] → [Стабилизатор] → U_вых → [Нагрузка]
```

| Блок | Преобразование |
|---|---|
| 1. Трансформатор | высоковольтное → низковольтное |
| 2. Выпрямитель | двухполярное → однополярное |
| 3. Фильтр | пульсирующее → квазипостоянное |
| 4. Стабилизатор | → стабилизированное |

## 1. Выпрямители

### Однополупериодный (полуволновой) выпрямитель
- Диод последовательно с нагрузкой $R_1$. Блокирует либо положительные, либо отрицательные
  полупериоды (если диод перевернуть — **инверсный выпрямитель**).
- Диод открыт, пока $V_\text{вх} > V_{Д,откр}$; тогда

$$V_\text{вых} = V_\text{вх} - V_{Д,откр}$$

- Но выход пульсирующий → для получения постоянного напряжения **выход нужно фильтровать**.

### Выпрямитель с ёмкостным фильтром и нагрузкой
- Параллельно нагрузке $R_н$ — конденсатор $C_ф$.
- **Зарядка** ёмкости через малое сопротивление открытого диода: $\tau = R_ДC_ф$ — мало (быстро).
- **Разрядка** через большое $R_н$ (диод закрыт): $\tau = R_нC_ф$ — велико (медленно).
- Максимум выхода $V_p - V_{Д,откр}$; ёмкость разряжается через нагрузку → $V_\text{вых}$ не постоянно,
  есть **пульсации** $V_\text{пульс}$.

Разряд (обычный переходный процесс):

$$V_\text{вых}(t) = (V_p - V_{Д,откр})\exp\frac{-t}{R_нC_ф},\quad 0 \le t \le T_\text{вх}$$

Для большой $C_ф$ ($e^x \approx 1 + x$):

$$V_\text{вых}(t) \approx (V_p - V_{Д,откр})\left(1 - \frac{t}{R_нC_ф}\right) =
\underbrace{(V_p - V_{Д,откр})}_{\max} - \underbrace{\frac{V_p - V_{Д,откр}}{R_н}\cdot\frac{t}{C_ф}}_{\text{спад}}$$

**Пульсации однополупериодного выпрямителя** (разряд длится ≈ период $T_\text{вх}$):

$$\boxed{V_\text{пульс} \approx \frac{V_p - V_{Д,откр}}{R_н}\cdot\frac{T_\text{вх}}{C_ф} = \frac{V_p - V_{Д,откр}}{R_нC_ф f_\text{вх}}}$$

- Чем больше $C_ф$, тем меньше пульсации → $C_ф$ подбирают **под допустимые пульсации и допустимый
  ток диода** (большая ёмкость → большие импульсы зарядного тока).
- Пульсации становятся проблемой, если превышают **5–10 %** выходного напряжения.

### Коэффициент пульсаций
Выход выпрямителя — **пульсирующий**: полезная постоянная составляющая + ряд гармоник.

$$k = \frac{\Delta V_\text{вых}}{V_\text{вых.ср}}$$

- $\Delta V_\text{вых}$ — размах: разность наибольшего и наименьшего значений пульсирующего напряжения;
- $V_\text{вых.ср}$ — среднее (постоянная составляющая) на интервале, **кратном периоду**;
- определяется в **установившемся режиме** (после переходного процесса).

### Двухполупериодный выпрямитель
- **Идея:** пропускает оба полупериода, **инвертируя отрицательные**: $V_\text{вых} = |V_\text{вх}|$;
  пульсации на выходе **вдвое меньше**.
- Как получить схему: два однополупериодных (для «+» и «−» полуволн). Просто соединить два встречных
  диода нельзя — проходит любое напряжение. Однополупериодный выпрямитель с двумя диодами
  (по одному в каждом проводе): $V_\text{вых} = V_\text{вх} - 2V_Д$; инверсный вариант — с перекрёстным
  соединением. Две такие схемы на общую нагрузку = **мостовая схема (диодный мост D1–D4)**.
- Положительная полуволна: открыты D3, D4 (работает «выпрямитель»); отрицательная: D1, D2 (работает
  «инверсный выпрямитель»). Ток через нагрузку всегда в одном направлении.
- В каждом полупериоде ток идёт через **два** диода:

$$|V_\text{вых}| = |V_\text{вх}| - 2V_{Д,откр}$$

- **«Мёртвая» зона** около $V_\text{вх} = 0$: при $|V_\text{вх}| < 2V_{Д,откр}$ мост закрыт, $V_\text{вых} = 0$;
  при $|V_\text{вх}| > 2V_{Д,откр}$ выход повторяет форму $|V_\text{вх}|$.
- Токи диодов без фильтра: $I_{D3} = I_{D4}$ в «+» полупериод, $I_{D1} = I_{D2}$ в «−»; амплитуда
  $(V_p - 2V_{Д,откр})/R_н$.

### Мостовой выпрямитель с фильтром
- Зарядка $C_ф$ — быстро через открытые диоды, разрядка — медленно через $R_н$.
- Ёмкость разряжается **только полпериода** → пульсации **в 2 раза меньше**:

$$\boxed{V_\text{пульс} = \frac12\cdot\frac{V_p - 2V_{Д,откр}}{R_нC_ф f_\text{вх}}}$$

  (в «Заключении» лекции упрощённо: $(V_p - V_{Д,откр})/(2R_нC_ф f_\text{вх})$).
- **Дополнительное преимущество:** обратное напряжение на диодах ≈ $V_p$ (а не $2V_p$, как в полуволновом
  выпрямителе с конденсатором: там к закрытому диоду приложены $V_p$ входа + $V_p$ на конденсаторе).
- **Замечание:** входное и выходное напряжения отсчитываются **относительно разных точек** (нет общей земли).

### Сравнение рабочих схем (с фильтрами)
Показатели: пульсации выходного напряжения, уровень постоянного напряжения, обратное напряжение на
диодах, потребляемый ток, состав схемы.

| | Однополупериодный | Мостовой |
|---|---|---|
| число диодов | 1 | 4 |
| падение на диодах | $V_{Д,откр}$ | $2V_{Д,откр}$ |
| пульсации | $\dfrac{V_p - V_{Д}}{R_нC_ф f}$ | $\dfrac{V_p - 2V_{Д}}{2R_нC_ф f}$ (в 2 раза меньше) |
| обратное напряжение на диоде | ≈ $2V_p$ | ≈ $V_p$ |
| общая точка вход/выход | есть | нет |

Мостовой выпрямитель даёт меньшие пульсации — лучше для адаптеров и зарядных устройств.

*Пример для тренировки (не со слайдов):* $V_p = 5{,}66$ В, $V_{Д,откр} = 0{,}8$ В, $R_н = 100$ Ом,
$C_ф = 1000$ мкФ, $f = 50$ Гц. Полуволновой: $V_\text{пульс} = 4{,}86/(100\cdot10^{-3}\cdot50) ≈ 0{,}97$ В.
Мостовой: $(5{,}66 - 1{,}6)/(2\cdot100\cdot10^{-3}\cdot50) ≈ 0{,}41$ В.

## 2. Параметрические стабилизаторы напряжения

**Назначение стабилизатора — устранить недостатки выпрямителя:**
1. чувствительность к перепадам $V_\text{вх}$ → **постоянная** составляющая $V_\text{вых}$ ограничена
   напряжением открытия диодов / пробоя стабилитронов;
2. избыточный коэффициент пульсаций → **переменная** составляющая (пульсации) ослабляется
   эквивалентным резистивным делителем;
3. зависимость $V_\text{вых}(I_\text{нагр})$ → в параметрических стабилизаторах **не решена**.

**Основные параметры стабилизатора:**
- **коэффициент нестабильности по входу** (коэф. передачи по напряжению):
  $\Delta V_\text{вых}/\Delta V_\text{вх}$ при $I_н = \text{const}$;
- **коэффициент нестабильности по нагрузке** (выходное сопротивление):
  $\Delta V_\text{вых}/\Delta I_н$ при $V_\text{вх} = \text{const}$.

Схема: $V_\text{вх}$ → $R_1$ → выход; на землю — прямо включённый диод D1 ($V_{Д,откр} = 0{,}8$ В)
последовательно со стабилитроном D2 в пробое ($V_\text{проб} = 2{,}7$ В) → $V_\text{вых} ≈ 3{,}5$ В.
Малосигнальная схема: $R_1$ и $r_\text{диф} = r_{d1} + r_{d2}$ — делитель:

$$v_\text{вых} = v_\text{вх}\frac{r_\text{диф}}{r_\text{диф} + R_1}$$

### Пример: расчёт коэффициентов нестабильности
**Дано:** $R_1 = 100$ Ом, $r_{D2} = 5$ Ом, $V_\text{вх} = 5$ В, $V_{D,вкл} = 0{,}8$ В, $V_\text{проб} = 2{,}7$ В.

1. Оба коэффициента — малосигнальные → сначала рабочая точка (общая для обоих случаев).
2. Рабочая точка: диодная ветвь открывается при $0{,}8 + 2{,}7 = 3{,}5$ В;
   $I_{D1} = (V_\text{вх} - V_{D,вкл} - V_\text{проб})/R_1 = (5 - 3{,}5)/100 = 15$ мА;
   $r_{D1} = \varphi_T/I_{D1} = 26\text{ мВ}/15\text{ мА} = 1{,}73$ Ом.
3. По входу ($i_н = 0$ — обрыв нагрузки):
   $\dfrac{\Delta V_\text{вых}}{\Delta V_\text{вх}} = \dfrac{r_{D1}+r_{D2}}{r_{D1}+r_{D2}+R_1} = \dfrac{6{,}73}{106{,}73} = 0{,}063$.
4. По нагрузке ($v_\text{вх} = 0$ — вход заземлён):
   $\dfrac{\Delta V_\text{вых}}{\Delta I_н} = (r_{D1}+r_{D2})\,\|\,R_1 = \dfrac{6{,}73\cdot100}{106{,}73} = 6{,}31$ Ом.

## 3. Умножители напряжения

Зачем: часто в устройстве один источник питания, а отдельным узлам нужно другое напряжение.
Меньшее — делителем; меньшее/большее — трансформатором; **удвоитель (умножитель) легче и дешевле
трансформатора**. Применения: подсветка ЖК-дисплеев, копировальные аппараты, источники СВЧ (лампы
бегущей волны), ускорители частиц, накачка лазеров, питание индикаторов (пример — часы на ВЛИ IV-18).

### Конструируем удвоитель
1. **Детектор пика:** диод последовательно, $C_1$ на землю → $C_1$ заряжается до пика:
   $V_\text{вых} ≈ +V_p$ (точнее $V_p - V_{Д,откр}$).
2. Меняем местами диод и ёмкость ($C_1$ последовательно, диод на землю) → выход «прижат» сверху к 0,
   колеблется от 0 до $-2V_p$.
3. Переворачиваем диод → **«сдвигатель уровня» (фиксатор)**: синусоида сдвинута вверх на $V_p$,
   колеблется от 0 до $+2V_p$.

### Полная схема удвоителя
**Сдвигатель уровня** ($C_1$, D1) + **детектор пика** (D2, $C_2$). Напряжение в узле X колеблется
между 0 и $2V_p$; детектор пика заряжает $C_2$ до пика узла X. Выход растёт на
$V_p,\ V_p/2,\ V_p/4,\ \ldots$ за каждый следующий период, пока не достигнет **$2V_p$**.

## Ключевые выводы
1. Диоды применяются в выпрямителях, ограничителях, умножителях напряжения и переключателях (сдвигателях) уровня.
2. Однополупериодный выпрямитель передаёт одну полуволну и блокирует другую; с конденсатором на выходе
   напряжение почти постоянное, почти равное пику входного.
3. Пульсация полуволнового выпрямителя: $(V_p - V_{Д,откр})/(R_нC_ф f_\text{вх})$.
4. Двухполупериодный выпрямитель даёт выход одной полярности из входа обеих полярностей; пульсация
   вдвое меньше: $(V_p - V_{Д,откр})/(2R_нC_ф f_\text{вх})$ (для моста точнее $V_p - 2V_{Д,откр}$).

## Возможные вопросы
- Структура адаптера питания, функция каждого блока.
- Однополупериодный выпрямитель с ёмкостным фильтром: вывод формулы пульсаций.
- Коэффициент пульсаций: определение.
- Мостовой выпрямитель: как работает, мёртвая зона, пульсации, обратное напряжение на диодах.
- Параметрический стабилизатор: назначение, коэффициенты нестабильности, расчёт по малому сигналу.
- Удвоитель напряжения: детектор пика, сдвигатель уровня, как выход достигает $2V_p$.
